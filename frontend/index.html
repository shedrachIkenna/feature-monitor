How to read this

  1. Each solid line is a drift score: how different the latest 500 requests look from normal traffic.
  2. The dashed line is that detector's alarm level; a red point is a check that crossed it.
  3. Compare each line only with its own dashed line; the two detectors use different scales.
  4. An alert means "traffic changed", not "something is wrong": open Features to see what changed.
