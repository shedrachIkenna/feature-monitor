How to read this

  1. Each solid line is a detector's drift score (how unlike normal traffic the latest 500 requests look), divided by its alarm level.
  2. Above the dashed line at 1 means an alert; red points mark those checks.
  3. Both lines share this scale, so you can see which detector crossed first.
  4. An alert means "traffic changed", not "something is wrong": open Features to see what changed.

Drift score over time, per detector, relative to its alarm level

Higher means the latest 500 requests look less like normal traffic. Each line is that detector's drift score divided by its own threshold, so the dashed line at 1 is the alarm level for both.
